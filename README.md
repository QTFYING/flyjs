## 📦 运行 & 发布

```bash
# 初始化
$ pnpm install

# 运行
$ pnpm dev

# 打包
$ pnpm run build

# build library source code in watch mode
$ pnpm run build:watch

# build docs
$ pnpm run docs:build

# Locally preview the production build.
$ pnpm run docs:preview

# check your project for potential problems
$ pnpm run doctor
```
